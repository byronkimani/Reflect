# Versioning Scheme

Reflect follows standard **Semantic Versioning (SemVer)** with a monotonic build number, structured as:
`MAJOR.MINOR.PATCH+BUILD`

## Definitions

- **`MAJOR`**: Increment when making massive architectural changes or completely overhauling the UI in a way that significantly changes the user experience.
- **`MINOR`**: Increment when adding new features or functionality (e.g., adding Google Calendar Sync, new Analytics charts).
- **`PATCH`**: Increment for bug fixes or minor internal improvements that do not add new user-facing features.
- **`BUILD`**: A monotonic integer that **must** increment with every single APK generated and uploaded to App Testers or the Play Store.

### Platform Mapping
When `flutter build apk` runs, it maps this string to the native Android formats:
- `MAJOR.MINOR.PATCH` becomes the **`versionName`** (e.g., `1.0.0`). This is what users see.
- `BUILD` becomes the **`versionCode`** (e.g., `2`). This is what Android and Firebase use to determine if an app is "newer" than the currently installed one.

## Firebase App Distribution
When an APK is uploaded to Firebase App Distribution, Firebase automatically extracts the `versionName` and `versionCode` from the compiled APK. You do not need to rename the APK file itself; Firebase will display it as `Release 1.0.0 (2)` in the dashboard and tester emails.

## Release Process
Before merging a PR that is intended to trigger a new distribution to the `qa-team`, the developer must manually bump the `MAJOR.MINOR.PATCH` version string in `pubspec.yaml` (e.g., from `1.0.0` to `1.0.1`).

**Release Notes:** When sending out a new feature, you must also prepare and include release notes documenting the changes for users and app testers.

**Note:** The `+BUILD` number in `pubspec.yaml` (e.g. `+1`) is ignored by the CI pipeline. GitHub Actions automatically injects the exact workflow Run Number as the build number (e.g., `flutter build apk --build-number=42`). This guarantees every single APK generated by CI has a strictly monotonic and unique build number without any manual intervention!
